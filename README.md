# AlphaTrade — Android Trading App

An Android trading-app prototype with market overview, portfolio, watchlist, news, onboarding, and profile experiences.

## Features

- Market and asset overview
- Portfolio and watchlist screens
- Market news interface
- User onboarding and profile screens
- Native Android interface built with Jetpack Compose

## Technology

Kotlin · Jetpack Compose · AndroidX · Room · Retrofit · OkHttp · Firebase AI

## Build

Requirements: Android Studio and a compatible JDK/Android SDK.

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle sync to complete.
4. Run the `app` configuration on an emulator or Android device.

## Project Status

Prototype application. Connected market data, account services, and trading capabilities depend on the integrations configured in the source.
